# @voie-libre/api-client

Typed client for the Voie Libre API, generated from the API's OpenAPI document.

- `openapi.json`: the spec served by the API on `/openapi.json` (committed).
- `src/schema.d.ts`: TypeScript types generated by `openapi-typescript` (committed, do not edit).
- `src/index.ts`: `createApiClient({ baseUrl })`, a thin wrapper around `openapi-fetch`.

Regenerate after changing an API schema, with no server running:

```bash
npm run generate-client
```

CI fails when regenerating leaves a diff.
